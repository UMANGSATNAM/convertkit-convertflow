# ShopForge — ADVANCED PDP Spec (Phase A focus)

Reframe: the PDP is NOT one element (sticky ATC) — it's a **complete, rich, conversion-optimized page**.
Distilled from 9 real advanced PDPs (Huel, Skoon, Velora, Cyrusher e-bike, Silken Strands, Sports Bras,
Biolift, Hari Masala). Build **complete PDP archetypes** that compose the blocks below — verify at the
whole-PDP level, not a lone element. Sticky ATC = ONE block inside this.

Every block: token-driven · real-data-only · mobile-first · premium bar · edge-cases. Read 05-RULES.md.

---

## A. PDP BUILDING BLOCKS (the pieces every advanced PDP draws from)

**Media**
1. Gallery — thumbnail-column / carousel-with-dots / grid; zoom; optional "How it works" video.
2. On-image badges — bestseller / new / sale / % off (real tags/data only).

**Info + price**
3. Title + subtitle / category / vendor (bilingual-capable for India).
4. Rating + review count + "see reviews summary" link (REAL reviews only).
5. **Price box** — current + compare-at (struck) + save% / "Save X Today" + tax/shipping note; often a highlighted box.
6. **Benefit checklist** — checkmark list of key USPs (the single most common advanced-PDP element).
7. Benefit icon chips — vegan / lab-tested / gluten-free / made-in etc.

**Choice**
8. Variant selectors — colour swatches, size chips/circles + **size guide** modal, scent, material.
9. Quantity selector.
10. **Bundle / pack selector** — "Pack of N" with POPULAR / BEST DEAL badges + save%.
11. **Subscription vs one-time** — subscribe-&-save (Save X%), "how subscriptions work".

**Convert**
12. Primary CTAs — Add to Cart + **Buy Now / instant checkout** + wishlist heart.
13. Express / financing — Apple/Google/Shop Pay, PayPal; **EMI / BNPL / Affirm** (big for India + high-ticket).
14. **India D2C** — "Order on WhatsApp" chat + **COD** callout (key for Indian merchants).
15. **Urgency / social proof** — "Only X left" + stock progress bar, "X sold", "X people browsing" —
    **REAL data or OMITTED** (browsing/viewing counts are the most-faked; never fabricate).

**Trust**
16. Trust badges row — free shipping / easy returns / secure payment.
17. Payment-method badges — Visa / Mastercard / UPI / Apple Pay.
18. Delivery info — estimated delivery dates, fast-dispatch, COD.
19. Guarantee line — money-back / quality / taste guarantee.

**Depth (below the fold)**
20. Tabs / accordion — Description · Reviews · FAQ · Materials · Shipping · Lab Report.
21. Specs grid — range / speed / battery / material etc. (tech/hardware).
22. Cross-sell — compatible accessories / frequently-bought-together (checkbox add-ons).
23. Reviews section — with photos, rating breakdown, Q&A.
24. Related — "You May Also Like" / recently-viewed.
25. **Sticky ATC bar** (bottom) — the block already built (v1 minimal / v2 urgency / v3 variant).

## B. COMPLETE PDP ARCHETYPES (each composes the blocks differently — structurally distinct pages)

1. **Supplement / FMCG** (Huel, Skoon) — benefit-checklist-forward + benefit chips + subscription-vs-one-time + big save badge + reviews-summary + guarantee. Wellness/food/grocery.
2. **Apparel / Fashion** (Velora) — thumbnail-gallery + colour swatches + size + size-guide + tabs (details/materials/size/shipping) + lifestyle image + You-May-Also-Like. Clothing/footwear.
3. **Tech / Hardware** (Cyrusher) — carousel gallery + specs grid + **financing/EMI** + **compatible-accessories cross-sell** + low-stock progress. Electronics/appliances/high-ticket.
4. **Beauty / Cosmetics** (Silken Strands) — how-it-works video + shade/pack selector + **bundle (POPULAR/BEST DEAL)** + subscribe-&-save + ingredients/how-to-use. Beauty/skincare.
5. **India D2C** (Hari Masala) — bilingual-capable + **WhatsApp order + COD** + price-box "Save Today" + verified-reviews + benefit chips + dispatch/COD/guarantee row + sticky ATC. Tuned for Indian market — likely the default archetype for most ShopForge clients.
6. **Minimal / Editorial** (Sports Bras) — clean, restrained; benefit checklist + swatches + estimated delivery + lots of whitespace. Premium/luxury/DTC.
7. **High-urgency / Conversion** (Biolift) — social-proof counters (sold/verified) + urgency (only X left) + Buy-Now-forward + trust/payment badges + tabs. Aggressive conversion — **all counters REAL data only**.

**How this scales:** 7 archetypes × the block variants × token sets → many complete advanced PDPs. The
generation engine picks the archetype by niche (supplement store → #1, jewelry → #6, electronics → #3, most
Indian D2C → #5) and adapts to the merchant's real catalog/data.

## C. Build approach (prove-then-scale, at the PDP level)

1. Build **ONE complete advanced PDP archetype** end-to-end — recommend **#5 India D2C** (matches most target
   clients + the Hari Masala bar Umang already likes). Compose all relevant blocks, real product data, premium bar.
2. **Render-verify** on a real preview link (Umang's eyes, mobile + desktop) — must look as complete/premium as
   the references, not a simple page. Scroll the whole PDP; check sticky ATC triggers; check real-data blocks
   hide when data absent.
3. After verify → build the other archetypes (#1-#7), then variant + token depth.
4. Keep the block library (section A) reusable — each block is a snippet/section the archetypes share.

**Data integrity (critical — references are full of it):** sold-count, "X browsing", "only X left",
verified-review counts, save% — all from REAL merchant data (inventory, orders, reviews app, compare_at_price),
hidden if absent. Copy the LOOK of the references, never their invented numbers.

## D. Scaling to 100 (gated batches of 10)

Target: **100 complete advanced PDP designs**, each a different archetype/layout. Built in **gated batches of 10**
— NOT blind mass-generation (that's how the earlier 6 cards / 206 sections went generic).

**The loop:**
1. Build **10** complete advanced PDPs. Each: a different archetype/layout (rotate the 7 archetypes + variations),
   all blocks composed, real product data, token-driven, mobile-first, premium bar (Hari-Masala level or better),
   real-data-only. Rich/complete — completeness+quality is the goal, NOT line-count (no bloat to hit a number).
2. **Gate:** after each 10, a real preview link (mobile+desktop) of 2-3 of them → verify they clear the premium bar.
3. Premium → next 10. Any generic → fix the pattern BEFORE the next batch (don't repeat a generic batch 10×).
4. Repeat to 100. Tracker updated per design (archetype + verified y/n).

Reminder: for pure uniqueness ~30 is already infinite via combinations; the 100 is for depth/style-coverage.
What makes 100 worth more than 30 is that ALL 100 clear the premium bar — the gate is what guarantees that.
