# ShopForge — Section List (what to build)

**Target: ~30 variants per section type.** Every variant: CRO-tested · mobile-first responsive · token-driven ·
real-data-only · premium bar · edge-cases handled. Priority: **P0** core conversion · **P1** strong lift · **P2** polish.

Build order: P0 sections first (PDP + cart + overlays + homepage-trust + filters), then P1, then P2.
Within each section type: prove ~2-3 variants render-verified premium, then scale to 30.
