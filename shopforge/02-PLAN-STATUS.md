## Phased plan

- **Phase A — Section library to premium bar.** For each section type, build/level ~30 CRO-tested, premium,
  mobile-first variants. Prove one type render-verified, then scale. Priority order = 03-SECTION-LIST.md
  (PDP suite first — biggest conversion gap).
- **Phase B — Blueprints.** Per-niche recipes (style + palette + section-mix + copy). Start with 3-4 niches.
- **Phase C — Selection engine.** Rules: DNA → blueprint → variant pick → coherence filter → catalog-adapt →
  token set. The moat. Build + test it picks coherent, fitting, non-colliding stores.
- **Phase D — Assembly + 3-preview generator.** Compose templates, wire real products, output 3 different previews.
- **Phase E — Publish pipeline.** Compile → push to Shopify as draft → user sets live. (+ ZIP option.)
- **Phase F — CRO layer + end-to-end test** on a real merchant store; verify responsive + non-colliding + real-data.

## Discipline (applies every phase)
Prove one, verify on a real render (user's eyes / real preview link — not local-path screenshots), then scale.
Count ≠ quality: a section isn't "done" until it's render-verified against the premium bar.
