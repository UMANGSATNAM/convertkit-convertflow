# 01 EXECUTIVE SUMMARY

ConvertKit Pro is a single Shopify app that replaces 15+ individual apps, giving Indian D2C merchants a fully optimized, conversion-ready store without needing a developer or multiple subscriptions. One installation, 30-minute setup, and the store is ready to convert.

- **Target Market**: Indian D2C Shopify merchants
- **Apps Replaced**: 15+ (Loox, ReConvert, Flair, Sales Pop, etc.)
- **Pricing**: Rs.999 / Rs.1,999 / Rs.3,499 per month
- **Merchant Savings**: Rs.8,000 to Rs.22,000 per month
- **Infrastructure**: Railway (MySQL + Redis)
- **Framework**: Shopify App — Remix + TypeScript

## The Problem
A typical Indian D2C Shopify store owner managing 50-500 orders/month currently pays Rs.10,000-25,000/month across 8-12 apps, suffers from slow store speed due to conflicting JavaScript bundles, has zero India-native features (COD management, GST invoicing, Shiprocket, pincode checker), and needs to hire a Shopify developer just for basic setup. ConvertKit Pro eliminates all of this.
